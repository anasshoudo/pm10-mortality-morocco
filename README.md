# PM10-Attributable Mortality in Morocco (2021)

Code accompanying Houdou et al., "Estimation of Mortality Attributable to
Particulate Matter (PM10) Exposure in Morocco in 2021" (submitted to GeoHealth).
Computes relative risk, attributable proportion, and attributable mortality
cases among adults from CAMS PM10 reanalysis and WHO AirQ+
concentration-response functions.
